# Онлайн калькулятор

## О проекте

Онлайн-калькулятор с поддержкой базовых и инженерных операций, памяти, адаптивным дизайном и приятным внешним видом. Работает полностью на стороне клиента (HTML, CSS, JS).

## Особенности
- Семантическая и доступная разметка
- Современный внешний вид (неоморфизм, плавные анимации)
- Адаптивность: отлично выглядит на мобильных и десктопах
- Поддержка операций: +, -, ×, ÷, %, √, x², 1/x, смена знака, запятая
- Кнопки памяти: MC, MR, M+, M-, MS
- Быстрый отклик и удобное управление

## Структура проекта
- `index.html` — основная страница с разметкой калькулятора
- `styles/calc.css` — стилизация и адаптивность
- `js/calc.js` — логика калькулятора
- `js/main.js` — инициализация
- `images/` — иконки и изображения

## Технологии
- HTML5 (семантика, доступность)
- CSS3 (Grid, переменные, адаптив, неоморфизм)
- JavaScript (ES6+)
